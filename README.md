# Final Project

## Emotion Detection Application

This repository contains the source code for an AI-based emotion detection web application developed using Python, Flask, and the Watson NLP Emotion Predict library.

### Description
The application analyzes user-provided text through an API and returns emotional metrics including anger, disgust, fear, joy, sadness, along with the dominant emotion. It also includes comprehensive error-handling routines, unit test coverage, and complies with PEP 8 styling guidelines evaluated via Pylint.
